# v2.4 Features

- Funding / Loans module: lender, principal, start date, bank details, percentage or fixed interest, monthly/quarterly/yearly schedules.
- Scheduled interest payment button; posts to bank/cash and reduces finance profit.
- Dashboard business pulse, next funding payment, average monthly realised earning, monthly trend charts.
- CSV migration import with preview for the supplied legacy columns. Import creates parties, purchase/cost, payment allocation and financing receivable records; generated records remain editable in normal modules.
- Safe TEST -> LIVE promotion only when LIVE is empty. No overwrite of live financial data.
- Currency display uses Indian Rupee format with zero decimal places.
