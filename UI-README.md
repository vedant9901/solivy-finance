# SOLIVY Finance Manager — Responsive UI

This build keeps the finance/database/API logic and upgrades the UI for desktop, tablet and mobile screens.

## Responsive behavior
- Desktop (lg+): fixed dark sidebar navigation and spacious content area.
- Tablet: compact responsive cards/forms and horizontally scrollable data tables.
- Mobile: sticky horizontal module navigation, touch-friendly controls, stacked forms, and horizontally scrollable tables.
- Inputs have stable focus states and larger touch targets.
- Tables intentionally scroll horizontally rather than collapsing financial columns into unreadable text.

## UI direction
- SOLIVY branding
- Orange primary action color
- Deep navy navigation
- White finance cards
- Clear LIVE/TEST environment indicator
- Consistent buttons, form fields, table headers, status areas and spacing
