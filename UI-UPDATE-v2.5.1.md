# v2.5.1 UI refresh

Built directly from the stable v2.5 commercial-bills/import/security build. Functional finance APIs and database logic are unchanged.

## UI changes
- Premium SOLIVY visual identity
- Cleaner desktop sidebar and active states
- Glass/frosted top bar
- More restrained card shadows and spacing
- Smooth page/card entrance animations
- Hover/press micro-interactions
- Preserved the v2.5 mobile module selector and responsive table behavior
- 16px mobile inputs to prevent browser zoom/focus issues
- Safe-area support on mobile
- `prefers-reduced-motion` support
- Removed duplicate Commercial Bill action
- Default display branding changed to SOLIVY
