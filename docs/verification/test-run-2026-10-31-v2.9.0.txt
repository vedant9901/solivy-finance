## Architecture identified (not assumed)
Online storage holds the whole organisation SQLite file in PostgreSQL as 4 KiB page-aligned
Brotli chunks plus a base blob, with a manifest and optimistic versioning (lib/snapshot-store.ts).
Device <-> hub synchronisation on top of it is event replication through the sync_changes journal.
The system is therefore a HYBRID: a clone is a verified snapshot transfer, incremental sync stays
event-based. The clone engine is built on the existing chunk store, so only differing pages move.
