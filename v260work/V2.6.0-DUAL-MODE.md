# SOLIVY Finance v2.6.0 — True Dual Mode

## Modes

### Offline Windows
- `DEPLOYMENT_MODE=offline` (or no `DATABASE_URL`)
- Uses the existing persistent SQLite LIVE/TEST files.
- Existing local data remains outside the application folder.

### Online Vercel
- `DEPLOYMENT_MODE=online`
- `DATABASE_URL` points to Neon/PostgreSQL.
- All Next.js UI and `/api/*` routes are deployed in the same Vercel project.
- Company isolation is implemented with separate PostgreSQL schemas for each company/environment (`LIVE` and `TEST`).
- No SQLite database is used for production Vercel requests.

## Required Vercel variables

- `DATABASE_URL` — complete Neon PostgreSQL connection string.
- `SESSION_SECRET` — long random secret.
- `DEPLOYMENT_MODE=online`

Optional:
- `INITIAL_ADMIN_PASSWORD` can be used by a future initialization layer; the current bootstrap keeps the existing default admin behavior for compatibility.

## First online request

The API safely creates the `solivy_admin` schema, the SOLIVY company, admin/tester users, and the company LIVE/TEST schemas if they do not already exist. Existing PostgreSQL data is not purged.

## Important

Do not deploy a local SQLite database to Vercel and do not set `FINANCE_DATA_DIR` on Vercel.
